# Python-Glossar

[Start](README.md) · [Index](INDEX.md)

| Begriff | Einfach erklärt |
| --- | --- |
| Argument | Der konkrete Wert beim Funktionsaufruf, etwa 3 in double(3). |
| Attribut | Eine Eigenschaft eines Objekts, etwa note.title. |
| Boolean | Ein Wahrheitswert: True oder False. |
| Callback | Eine Funktion, die du übergibst, damit anderer Code sie später aufruft. |
| CLI | Bedienung eines Programms über Terminalbefehle und Argumente. |
| Closure | Eine Funktion, die Namen aus einem umschließenden Funktionsbereich weiterhin erreichen kann. |
| Comprehension | Eine kurze Schreibweise zum Erzeugen einer Sammlung aus anderen Werten. |
| Context Manager | Ein Objekt für with-Blöcke, das Einrichtung und Abschluss einer Aktion steuert. |
| Coroutine | Ein asynchroner Ablauf, der kooperativ warten und später fortgesetzt werden kann. |
| CRUD | Anlegen, Lesen, Ändern und Löschen von Daten. |
| Dataclass | Eine Datenklasse, für die Python wiederkehrende Methoden automatisch erzeugen kann. |
| Decorator | Eine Funktion, die eine andere Funktion oder Klasse verarbeitet beziehungsweise erweitert. |
| Dependency | Eine Abhängigkeit: ein benötigtes Paket, Objekt oder externer Dienst. |
| Dictionary | Eine Zuordnung eindeutiger Schlüssel zu Werten. |
| Docstring | Ein Dokumentationstext am Anfang eines Moduls, einer Klasse oder einer Funktion. |
| Exception | Ein Fehlerobjekt, das den normalen Programmablauf unterbrechen kann. |
| Factory | Eine Funktion oder ein anderes aufrufbares Objekt, das neue Objekte erzeugt. |
| Float | Eine Gleitkommazahl. Viele Dezimalbrüche sind darin nicht exakt darstellbar. |
| Generator | Ein Iterator, der Werte nach Bedarf erzeugt, beispielsweise mit yield. |
| Hashbar | Als stabiler Schlüssel nutzbar; unter anderem Voraussetzung für Dictionary-Schlüssel und Set-Elemente. |
| Idempotent | Mehrfach ausgeführt hat eine Aktion bezüglich ihres beabsichtigten Effekts dasselbe Ergebnis wie einmal. Das ist unter anderem für Wiederholungen wichtig. |
| Immutable | Unveränderbar: Der Wert eines solchen Objekts wird nicht an Ort und Stelle verändert. |
| Import | Ein verfügbares Modul oder Namen daraus im Programm zugänglich machen. |
| Index | Eine Position in einer geordneten Sammlung; in Python beginnt sie normalerweise bei 0. |
| Instanz | Ein konkretes Objekt einer Klasse. |
| Integer | Eine ganze Zahl vom Typ int. |
| Iterable | Ein Objekt, dessen Elemente du durchlaufen kannst. |
| Iterator | Ein Durchläufer mit eigener aktueller Position und einer next-Operation. |
| JSON | Ein textbasiertes Datenformat für Werte, Listen und Objekte mit String-Schlüsseln. |
| Konvention | Eine gemeinsame Vereinbarung, beispielsweise snake_case; nicht jede Konvention ist eine technische Pflicht. |
| Linting | Automatische Prüfung ausgewählter problematischer Code-Muster und Stilregeln. |
| Liste | Eine geordnete, veränderbare Sammlung, die auch doppelte Werte enthalten kann. |
| Lockdatei | Eine Datei, die einen aufgelösten Abhängigkeitsstand für reproduzierbare Installationen beschreibt; Details hängen vom Werkzeug ab. |
| Methode | Eine Funktion, die zu einer Klasse gehört und häufig auf deren Instanz aufgerufen wird. |
| Modul | Eine importierbare Codeeinheit, im Alltag meist eine Python-Datei. |
| Mutable | Veränderbar: etwa eine Liste, deren Inhalt du mit append() erweiterst. |
| None | Ein eigener Wert für fehlende oder nicht vorhandene Ergebnisse. |
| Paket | Eine Einheit aus zusammengehörigen Modulen; ein reguläres Importpaket hat eine __init__.py. |
| Parameter | Ein benannter Platzhalter in der Funktionsdefinition. |
| Parser | Code, der einen strukturierten Text nach dessen Regeln einliest. |
| PEP | Python Enhancement Proposal: ein Dokument für Sprachvorschläge oder Konventionen. PEP 8 beschreibt unter anderem Codestil. |
| Referenz | Ein Verweis auf ein Objekt. Mehrere Namen können dasselbe Objekt erreichen. |
| Regression | Ein früher behobener Fehler, der durch eine spätere Änderung wieder auftritt. |
| Return | Die Rückgabe eines Ergebnisses an den Aufrufer; nicht dasselbe wie eine Bildschirmausgabe. |
| Scope | Der Bereich, in dem ein Name gebunden beziehungsweise auflösbar ist. |
| Seiteneffekt | Eine Wirkung außerhalb des Rückgabewertes, etwa Dateischreiben oder Ändern einer übergebenen Liste. |
| Serialisierung | Umwandlung von Daten in ein speicher- oder übertragbares Format. |
| Set | Eine Sammlung eindeutiger hashbarer Werte ohne verlässliche Indexreihenfolge. |
| Slice | Ein Ausschnitt mit Start, exklusivem Ende und optionaler Schrittweite. |
| Standardbibliothek | Die mit Python ausgelieferten Module; nicht sämtliche installierbaren Pakete. |
| String | Ein Textwert vom Typ str. |
| Traceback | Die Aufrufkette und Codepositionen, die zu einem Fehler geführt haben. |
| Transaktion | Eine zusammengehörige Gruppe von Datenänderungen mit gemeinsamem Speichern oder Zurücknehmen. |
| Tupel | Eine geordnete Sammlung, deren direkten Einträge nach der Erzeugung nicht ersetzt werden. |
| Type Hint | Eine Typbeschreibung für Menschen, Editoren und Typprüfungen; keine automatische Eingabevalidierung. |
| Validierung | Prüfen, ob Form und Bedeutung von Daten zu den Anforderungen passen. |
| Virtuelle Umgebung | Eine projektbezogene Python-Umgebung mit eigenständig installierten Paketen. |
| Wheel | Ein gebautes Python-Distributionsformat, das mit einem Installer installiert werden kann. |
